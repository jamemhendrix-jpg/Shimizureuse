# 🧭 100億コンパス

**資産100億円・自由な生活・好きな車** — 大きな目標を「今日の一歩」に変える、毎日開くための目標達成アプリ。

## 使い方

`index.html` をブラウザで開くだけ。インストール・サーバー・アカウント不要。
スマホなら、ページをホーム画面に追加すると毎日ワンタップで開けます。

データはブラウザの localStorage にのみ保存されます(外部送信なし)。
「設定とデータ」からJSONで書き出し/読み込みができます。

## 設計思想: ゼロモチベーションの日でも開ける

- **開くだけで前進** — アプリを開いた日が自動で記録され、「開いた記録 ◯日連続」が伸びる。何も入力しなくていい。
- **目標を忘れさせない** — 「きょう」画面の一番上に、100億円・自由・好きな車が毎日必ず表示される。
- **デフォルトは「きょう」画面だけ** — 今日の一言、行動チェック、いまの位置。3秒で閉じてもOK。
- **分析は「ダッシュボード」に退避** — 見たい日だけ見る。
- **貯蓄フェーズ** — 資産100万円までは投資の話を出さない。「毎月の積立→100万円の到達予定」だけに集中。シミュレーションも100万円到達後にのみ年利を適用する。

## 機能

### きょう(デフォルト画面)
- 3つの目標チップ(💰100億円 / 🕊自由な生活 / 🚗ガレージの車)
- 日替わりの一言メッセージ
- 開いた記録の連続日数(自動)/ 毎日リマインド通知の設定
- 今日の行動チェック(習慣トラッカー・連続日数・直近7日ドット)
- 現在資産と次のマイルストーンへの進捗

### ダッシュボード
- **北極星ゴール**: 資産100億円 / 自由な生活(4%ルールによる経済的自由ライン) / 好きな車たち — それぞれの達成率
- **資産記録**: 「800万」「1.2億」のような日本語入力に対応。マイルストーン(100万→1,000万→…→100億)の進捗表示
- **資産推移チャート**: 実績と100億円への予測軌道(対数スケール・ホバー/キーボード操作対応・表による代替表示あり)
- **逆算シミュレーター**: 100万円までは貯蓄のみで計算。100万円以降は毎月の積立額と想定年利から100億円到達年・各マイルストーンの到達予定・目標年数に必要な利回りを逆算
- **ガレージ**: 好きな車を何台でも登録。価格はいつでも更新でき、常に最新の入力価格で達成率を計算

## 📈 導き — 週の賭けと上昇線(`guide.html`)

「コンパス」が地図なら、「導き」は**毎週やることを賭け、チェックで折れ線が動き、線が重なって「人生が上昇してるか」が見える**姉妹アプリ。
概念(数値化しない目標)は「好きな車に乗る、自由な生活」。そのための数値目標が100億円(コンパスの資産データを読むだけ)。
「きょう」画面の見出し下の「⚡ 導きへ」リンク(コンパス側)/「🧭 コンパスへ」リンク(導き側)で行き来できます。

- **概念ヘッダー**: 「好きな車に乗る、自由な生活」+「そのために — 100億」。コンパスに資産記録があれば「いま ◯◯円」を添える。
- **上昇イメージ**: 週替わり(毎週月曜)に1つ選ばれ、その週は固定表示される一言。初週・実感乖離・連続上昇・先週下落・高勝率・低勝率・マイルストーン接近・既定の8パターンを、週の記録から決定論的に選ぶ。
- **今週の賭け**: 今週やる項目(最大 slots 件、初期3・範囲1〜7)をタグ(稼ぐ/守る/増やす/整える)付きで登録し、チェックでクリア。チェックした瞬間に暫定スコア(線の先端)が動く。上限に達したら「今の枠は◯。枠は勝って増やす」と理由を明示。
- **清算**: 日曜になると「今週を清算する」ボタンが出現。押すと未クリア項目が−1として確定し、「『好きな車に乗る、自由な生活』に近づいた実感はあるか?」を1タップで記録、短い講評が表示される。清算し忘れた週も、翌週を開いた時点で自動清算される(実感はnullのまま)。
- **上昇線(チャート)**: SVG折れ線で、総合累積スコア(太)・実感累積(点線)・資産(薄い背景)・4週前までの自分(薄い過去線)を最大4本重ねて表示。「表で見る」でアクセシブルな表による代替表示も。タグ別の4本は「詳細」の折りたたみ内。データが2週分たまるまでは「線は2週目から現れる。まず今週を生き延びろ」と表示。
- **メンターのポジション管理**: 直近4週の勝率が2週連続で70%以上なら枠+1を、40%未満なら枠−1を提案し、ボタン一つで反映(上限7・下限1)。説教はせず、賭け金(枠)の話だけをする。
- **🤖 AI連携**: 週次データ(各週スコア・勝率・実感・タグ内訳・資産)を埋め込んだプロンプトで「Claudeに週次を見てもらう」または「査定文をコピー」。設定は一切不要。

「導き」のデータは `michibiki:v2` としてこの端末にのみ保存されます(旧 `michibiki:v1` は読み込まず、削除もしません)。コンパス側のデータ(`hyakuoku-compass:v1`)は読み取り専用で参照するだけで、書き換えることはありません。「設定とデータ」から導き側のデータ(`michibiki:v2`)のみJSONで書き出し/読み込みができます。

## 毎日リマインド(通知)

「きょう」画面の「🔔 毎日リマインドを設定」から通知を許可すると、毎日お知らせが届きます。

- 月曜は「上昇イメージ」の1文目+「今週の賭けを決めろ」、日曜は「清算の時間だ。線に今週の答えを刻め」が通知本文に載ります。それ以外の曜日は「導き」側からの新しい内容を書き込まないため、48時間を超えると自動的にこれまで通りの日替わりメッセージへフォールバックします。
- 通知には **Webとして公開されたURLが必要**です(`file://` では動きません)。このリポジトリをGitHub Pagesで公開するのが簡単です: リポジトリの Settings → Pages → Branch を選んで保存
- スマホで開いて「ホーム画面に追加」すると、アプリとしてインストールされ通知の配信が安定します(Android Chrome推奨。iOSは通知の対応が限定的です)

## 技術

- `index.html` + `sw.js` + `manifest.webmanifest`(依存なし・ビルド不要・オフライン動作)
- PWA対応(ホーム画面インストール・オフラインキャッシュ・Periodic Background Syncによる毎日通知)
- バニラJS + SVGチャート
- ライト/ダークモード自動対応(`prefers-color-scheme`)
- レスポンシブ(スマホ〜デスクトップ)
