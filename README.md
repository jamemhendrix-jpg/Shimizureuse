# 🧭 100億コンパス

**資産100億円・自由な生活・好きな車** — 大きな目標を「今日の一歩」に変える、毎日開くための目標達成アプリ。

## 使い方

`index.html` をブラウザで開くだけ。インストール・サーバー・アカウント不要。
スマホなら、ページをホーム画面に追加すると毎日ワンタップで開けます。

データはブラウザの localStorage にのみ保存されます(外部送信なし)。
「設定とデータ」からJSONで書き出し/読み込みができます。

## 設計思想: ゼロモチベーションの日でも開ける

- **開くだけで前進** — アプリを開いた日が自動で記録され、「開いた記録 ◯日連続」が伸びる。何も入力しなくていい。
- **目標を忘れさせない** — 「きょう」画面の一番上に、100億円・自由・好きな車が毎日必ず表示される。
- **デフォルトは「きょう」画面だけ** — 今日の一言、行動チェック、いまの位置。3秒で閉じてもOK。
- **分析は「ダッシュボード」に退避** — 見たい日だけ見る。
- **貯蓄フェーズ** — 資産100万円までは投資の話を出さない。「毎月の積立→100万円の到達予定」だけに集中。シミュレーションも100万円到達後にのみ年利を適用する。

## 機能

### きょう(デフォルト画面)
- 3つの目標チップ(💰100億円 / 🕊自由な生活 / 🚗ガレージの車)
- 日替わりの一言メッセージ
- 開いた記録の連続日数(自動)/ 毎日リマインド通知の設定
- 今日の行動チェック(習慣トラッカー・連続日数・直近7日ドット)
- 現在資産と次のマイルストーンへの進捗

### ダッシュボード
- **北極星ゴール**: 資産100億円 / 自由な生活(4%ルールによる経済的自由ライン) / 好きな車たち — それぞれの達成率
- **資産記録**: 「800万」「1.2億」のような日本語入力に対応。マイルストーン(100万→1,000万→…→100億)の進捗表示
- **資産推移チャート**: 実績と100億円への予測軌道(対数スケール・ホバー/キーボード操作対応・表による代替表示あり)
- **逆算シミュレーター**: 100万円までは貯蓄のみで計算。100万円以降は毎月の積立額と想定年利から100億円到達年・各マイルストーンの到達予定・目標年数に必要な利回りを逆算
- **ガレージ**: 好きな車を何台でも登録。価格はいつでも更新でき、常に最新の入力価格で達成率を計算

## ⚡ 導き — 司令塔アプリ(`guide.html`)

「コンパス」が地図なら、「導き」は司令塔。**開いた瞬間、次にやるべきことを1つだけ命じる**姉妹アプリ。
「きょう」画面の見出し下の「⚡ 導きへ」リンク(コンパス側)/「🧭 コンパスへ」リンク(導き側)で行き来できます。

- **今の指令**: 時間帯(朝・昼・夜)とコンパスの習慣消化状況・今週のミッションから、今やるべきこと1つだけを大きく指示。「✔ やった」「あとで」で次の指令へ。
- **迷ったら聞け(判断オラクル)**: 「金を使いたい」「サボりたい」「不安だ」「儲け話が来た」「疲れた」を押すと、2〜3問のはい/いいえで裁定(GO / 見送り / 条件付きGO)。貯蓄フェーズ(資産100万円未満)では支出・儲け話の裁定を厳しめに。直近の裁定3件を表示。
- **今週の3ミッション**: ISO週ごとに最大3つ。テンプレ提案+自由入力。前週の完了率を表示し、未完了は「持ち越す」ボタンで新週へ。
- **夜の締め(3タップ)**: 「前進した?」「無駄遣いした?」「明日の最初の一手」を記録。翌朝の指令に反映され、保存直後に短い講評を表示。
- **規律スコア(0〜100)**: 直近14日間の夜の締め実施率・前進日率・コンパス習慣消化率から算出。
- **🤖 AI査定**: アプリ自身がその場で書く講評(常時表示・外部送信なし)+ 好きなAIにも査定させられるプロンプト。設定は一切不要。

「導き」のデータは `michibiki:v1` としてこの端末にのみ保存されます。コンパス側のデータ(`hyakuoku-compass:v1`)は読み取り専用で参照するだけで、書き換えることはありません。「設定とデータ」から導き側のデータのみJSONで書き出し/読み込みができます。

### 🤖 AI査定

規律スコアのカードの下にある「🤖 AI査定」で、行動(規律スコア・夜の締め・今週のミッション・オラクル裁定履歴・コンパス連携情報)を振り返れます。設定は一切不要です。

- **アプリからの講評(常時表示・外部送信なし)**: アプリ自身が記録から生成する断定調の講評が、カードを開くたびに表示されます。「きょう」の一言(前進・無駄遣い・消化した指令)+「直近14日」の締め実施率・前進日数・無駄遣い日数・ミッション達成率・規律スコア・フェーズ。「📋 レビューをコピー」でこのテキスト(メンターの目を含む)をそのままコピーできます。
- **メンターの目(弱点分析・ローカル処理)**: 直近28日の行動パターンから弱点(浪費傾向・サボり傾向・不安傾向・記録切れ癖・曜日の崩れ・持ち越し癖)を検出し、証拠の数字と対策の一手つきで上位2件まで講評の下に表示します。すべて端末内で処理され、外部には送信されません。記録日が7日未満の間は「まだパターンを読むには記録が足りない」と表示します。検出済みのパターンは外部AI用プロンプトにも【検出済みの行動パターン】として埋め込まれ、AIに「弱点への処方箋」を出させる材料になります。
- **外部AI用プロンプト**: 「Claudeに行動を査定してもらう」を押すと、行動レポートを埋め込んだプロンプトで `https://claude.ai/new?q=...` を新しいタブで開きます。あなたのClaudeアカウント(claude.aiのログインセッション)にそのまま入力され、送信するだけで査定が返ります。データが送られるのはボタンを押した瞬間だけです。URLが長くなりすぎる場合は、オラクル裁定履歴の古い項目から自動で間引かれます。「📋 査定文をコピー」で同じプロンプトをクリップボードにコピーできるので、コピーして好きなAI(スマホのClaudeアプリなど)に貼り付けて使うこともできます。

## 毎日リマインド(通知)

「きょう」画面の「🔔 毎日リマインドを設定」から通知を許可すると、毎日お知らせが届きます。

- 「導き」を開いた直近48時間以内に決まった今の指令(夜なら翌朝の最初の一手)が、通知本文にそのまま載ります。しばらく開いていない場合は、これまで通りの日替わりメッセージにフォールバックします。
- 通知には **Webとして公開されたURLが必要**です(`file://` では動きません)。このリポジトリをGitHub Pagesで公開するのが簡単です: リポジトリの Settings → Pages → Branch を選んで保存
- スマホで開いて「ホーム画面に追加」すると、アプリとしてインストールされ通知の配信が安定します(Android Chrome推奨。iOSは通知の対応が限定的です)

## 技術

- `index.html` + `sw.js` + `manifest.webmanifest`(依存なし・ビルド不要・オフライン動作)
- PWA対応(ホーム画面インストール・オフラインキャッシュ・Periodic Background Syncによる毎日通知)
- バニラJS + SVGチャート
- ライト/ダークモード自動対応(`prefers-color-scheme`)
- レスポンシブ(スマホ〜デスクトップ)
